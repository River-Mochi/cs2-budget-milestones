# Budget + Milestones

Cities: Skylines II mod for city-start progression and budget controls.

## Features

- Set initial money for the next loaded limited-money city.
- Select a higher starting milestone and apply the game's normal milestone rewards.
- Add or subtract money with configurable hotkeys.
- Optional automatic money threshold support.
- Convert Unlimited Money saves to normal limited-money budgeting.

The Population + Money trends HUD/tooltips remain part of City Watchdog and are not included here.
