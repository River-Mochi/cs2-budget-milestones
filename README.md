# Budget + Milestones

Cities: Skylines II mod for city-start progression and simple budget controls.

## Features

- Set initial money for the next loaded limited-money city.
- Start at a higher milestone, or keep normal progression.
- Optionally disable milestone cash rewards while keeping other milestone rewards.
- Add or subtract money with configurable hotkeys.
- Optional Automatic Add Money keeps your balance above a selected threshold.
- Optional network demolition cost from 0% to 50%, while keeping normal vanilla refunds.
- Convert Unlimited Money saves to normal limited-money budgeting.
- Reset City Start settings back to vanilla defaults.

## Languages

Includes:
English, German, Spanish, French, Italian, Japanese, Korean, Polish,
Português Brasileiro, Português Portugal, Thai, Turkish, Ukrainian,
Vietnamese, Simplified Chinese, and Traditional Chinese.

Some languages require a separate game localization mod because Cities: Skylines II does not officially provide them.
